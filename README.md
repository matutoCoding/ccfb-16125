# 帆型设计与受风形态推演系统

面向帆板帆型设计的网页工具:帆型档案、索具配置、控制晶格形态编辑、受风形态推演、海上测帆照片反算比对、设计单输出。TypeScript + three.js + IndexedDB,纯前端、无后端。

## 运行

```bash
npm install
npm run dev        # 开发,默认 http://127.0.0.1:5173
npm test           # 17 项单元/验收测试(vitest)
npm run build      # 类型检查 + 生产构建到 dist/
```

首次启动自动写入种子数据:4.7 / 5.8 / 7.8 ㎡ 三张帆(同系列不同尺寸)、两根不同硬度桅杆(硬桅 25 / 软桅 15)。

## 三条验收指标如何保证

1. **晶格单点拖动,影响范围外顶点位移严格为 0**
   晶格位移用紧支撑光滑窗 `bumpWindow`(`src/core/mathUtils.ts`),窗外严格返回 0(非近似)。
   每个晶格点绑定一个撑条区间,高度窗在区间两条边界处位移与导数同时归零,弦向窗外也严格为 0。
   见 `src/core/__tests__/acceptance.test.ts` 的「验收1」,对区间外、撑条边界、弦向窗外逐点断言位移为 0。

2. **风速 0→满→0 帆面逐点回到原样**
   基础形态 `basePosition` 是 `(profile, rig, k)` 的纯函数,无内部状态、无随机源;
   风抖 `renderPosition` 只是按时间叠加在渲染层,不写入基础形态,测量与验收都基于 `basePosition`。
   见「验收2」对同一组顶点 k=0/0.5/1/0 的逐点 `toEqual` 往返断言。

3. **截面弦高比与手算值误差 ≤ 0.5 个百分点**
   截面在由扭转角定义的截面平面内构造,空间弦长恒等于名义弦长;
   `measureSection` 用与构造严格互逆的坐标变换投影求最深点,并做三点二次插值把最深点位置提到亚采样级。
   「验收3」对三张帆全部撑条、多个风速点断言反测弦高比与手算公式的误差 ≤ 0.5 个百分点。
   照片反算另有 `photo.test.ts` 验证单应往返与弦高比反算精度。

## 关键设计取舍

- **纯函数内核与渲染分离**:所有几何形变不依赖 three.js 或 DOM,可在 Node 下直接测试,这是三条硬指标能写成确定性自动化测试的前提。
- **风抖不进基础形态**:抖动按撑条间布面跨度定幅、在撑条线归零,只在渲染循环按时间叠加,保证风速往返与测量稳定。
- **照片反算与 3D 同构**:合成照片的测量条带用与 `measureBand` 同量纲的弦高比定义投影,使端到端偏差可复现、可验收。
